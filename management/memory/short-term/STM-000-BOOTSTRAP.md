# STM-000 — 短期记忆初始化

> 本文件仅用于说明短期记忆的初始化状态，**不构成一条经验**。真实条目从 STM-001 起。

| 字段 | 值 |
|---|---|
| 初始条目数 | 0（依据记忆模型 §4.1：无任务即无经验，禁止硬凑） |
| 建库时间 | 2026-09-23 |
| 当前条目 | 无 |
| 容量上限 | 12 |
| 容量策略 | 超出时优先丢弃 `confidence` 最低且 `salience: low` 的条目 |

短期记忆不是"待办清单"，也不是"任务日志"（那是 `worklog/` 的职责）。
它是**从任务中提炼出来、尚待验证的可复用经验**。写入前三问：

1. 这条经验在**下一个不同的项目/任务**里还能用吗？
2. 它能被证伪吗？（"这样派活比较顺"不行）
3. 它有具体证据吗？（哪个 task_id、什么结果）

三问有一问为"否" -> 不写。

本角色典型的**合格**短时记忆长这样（示例，尚未发生）：
"把'需求澄清'与'技术方案'拆成两个 task_id 分派，比合成一个任务少一轮返工" —— 可证伪、有 task_id 证据、跨任务可复用。
