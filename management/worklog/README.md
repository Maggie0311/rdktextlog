# worklog/ — 工作日志

只追加，不修改历史。

**日志格式（本节即全部要求，无需查阅他处）**

```
# WORKLOG — <角色代号>
> 只追加。格式：#<序号> [YYYY-MM-DD HH:MM] <动作> | <理由> | <结果/证据>

## YYYY-MM
- #1 [YYYY-MM-DD HH:MM] **<动作>**
  - 触发: ...
  - 做法: ...
  - 理由: ...
  - 结果: ...
  - 证据: <文件路径 / 邮件 ID>
  - 后续: ...
```

只追加：历史条目不得改写；更正一律用**新条目**并在条目中标注 `[更正: #N]`。
主日志文件：`WORKLOG.md`（按月分节）。
每条日志必须能回答：**触发什么 / 做了什么 / 为什么 / 结果如何 / 证据在哪**。

对本角色额外要求：每次分派、催办、打回、验收、请示用户，**各记一条**，并写明对应 `task_id`。
台账（`script/PROJECT-BOARD.md`）记"结果"，worklog 记"过程与理由"，两者不得互相替代。
