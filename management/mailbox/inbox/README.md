# inbox/ — 来信（开工必读）

规则：
1. 每次开工前**必须**先读完 inbox 中的未处理信件，再动任何文件。
2. 处理完的信移入 `../archive/YYYY-MM/`。
3. **例外**：带 `keep_in_inbox: true` 的**常驻文件**（如任命信）不归档，因为它们是角色每次开工都要重新确认的依据。
4. inbox 中不得滞留除常驻文件外的任何信件（架构 §4 第 8 步）。

当前常驻：
- `WELCOME-management.md` — R-002 任命信（授权依据、使命来源与首个任务）

本角色预期的高频来信类型：`RESULT`（交付回报）、`ISSUE`（阻塞/异议）、`QUERY`（澄清）、`DECISION`（framework_admin 仲裁结论）。
所有 `ISSUE` 必须 ≤1 轮内响应；`DECISION` 必须执行（可申诉一次）。
