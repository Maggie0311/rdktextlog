# script/ — 产物与脚本

本角色产出的可复用资产。**注意：项目源代码不在本目录**——源码落在仓库根的 `src/`（交付产物区，本角色唯一写入者，见 `05-CONVENTIONS v1.1 §7.1`）。

| 产物 | 命名 | 说明 |
|---|---|---|
| 代码风格与注释规范 | `CODE-STYLE.md` | 本角色的专业判断产物，**management 会用它作验收依据之一**；变更须先 NOTIFY |
| 实现说明 | `IMPL-<task_id>.md` | 每条任务的交付说明：改动清单 / 关键决策与理由 / 验证方式与输出 / 已知风险与未覆盖项 |
| 可复用脚本 | `<slug>.<ext>` | 构建、格式化、检查类辅助脚本（若有） |
| 产物登记 | `INDEX.md` | 本表 |

规范：命名 `<slug>.<ext>`，重大变更另存 `-v2` 不覆盖；**每个产物必须登记到 `INDEX.md`**。
