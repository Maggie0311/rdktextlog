# worklog/ — 工作日志

只追加，不修改历史。

**日志格式（本节即全部要求）**：`#<序号> [YYYY-MM-DD HH:MM] **<动作>**`，下辖 `触发 / 做法 / 理由 / 结果 / 证据`（可选 `后续`）。
只追加；更正用**新条目**并标注 `[更正: #N]`。
主日志文件：`WORKLOG.md`（按月分节）。
每条日志必须能回答：**触发什么 / 做了什么 / 为什么 / 结果如何 / 证据在哪**。

对本角色额外要求：
- 每条日志必须写明 `task_id`；
- "结果"必须含可复现证据（命令 / 测试输出 / commit 短 hash），不接受"已完成"三个字；
- 技术决策要写清楚**取舍理由**（为什么不用另一种做法），这是本角色最有价值的日志内容。
