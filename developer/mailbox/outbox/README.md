# outbox/ — 已发出邮件（冻结副本）

本目录中的邮件在发出即冻结，**不得修改**。需要更正时：发一封新信，purpose 用 `NOTIFY`，并在 `references` 中列原信 `mail_id`。

本角色发出的信有四类，都必须留副本：
1. `ACK` — 接活确认（收到 TASK 后 ≤1 轮）；
2. `RESULT` — 交付回报（**必须附可复现证据**：命令 + 输出摘要）；
3. `ISSUE` — 阻塞、异议、越界请求、技术方案异议（附风险与替代方案）；
4. `QUERY` — 澄清请求（AC 不可验收 / 依赖缺失 / 需求矛盾）。
