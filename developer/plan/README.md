# plan/ — 任务规划（PRR）

每个任务开工前先写一份 `PLAN-YYYYMMDD-<slug>.md`（骨架见 `_framework/templates/PLAN-TEMPLATE.md`）。

**无计划不动手**（违规 V2）。计划在 `status: done` 之前可持续更新，但要保留变更理由。

对本角色额外要求：计划中必须含**技术方案节**——打算怎么实现、为什么选这条路、
有哪些备选与取舍、哪些地方需要向 management 发 QUERY 澄清（对应 `ROLE-LIMIT §0` 的 HOW 自主）。
计划标题中的 `<slug>` 建议直接复用 `task_id`，便于与台账、邮件、IMPL 三方对齐。
