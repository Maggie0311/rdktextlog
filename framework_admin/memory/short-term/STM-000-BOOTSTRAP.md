# STM-000 — 短期记忆初始化

> 本文件仅用于说明短期记忆的初始化状态，不构成一条经验。真实条目从 STM-001 起。

| 字段 | 值 |
|---|---|
| 初始条目数 | 0（按记忆模型 §4.1，无任务即无经验，禁止硬凑） |
| 建库时间 | 2026-02-14 |
| 当前条目 | STM-001 / STM-002 / STM-003（见同目录） |
| 容量上限 | 12 |
| 容量策略 | 超出时优先丢弃 `confidence` 最低且 `salience: low` 的条目 |

短期记忆不是"待办清单"，也不是"任务日志"（那是 `worklog/` 的职责）。
它是**从任务中提炼出来、尚待验证的可复用经验**。判定标准（写入前自问）：

1. 这条经验在**下一个不同的任务**里还能用吗？
2. 它能被证伪吗？（"效果不错"不行）
3. 它有具体证据吗？（哪个任务、什么结果）

三问有一问为"否" -> 不写。
