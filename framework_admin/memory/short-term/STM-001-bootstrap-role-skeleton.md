## 观察 (Observation)
本次创建 `framework_admin/` 时，仅建立空目录不足以让角色可用；实际起作用的是每个目录下的 `README.md`（写明用途、命名、写入规则、生命周期），以及 `_framework/templates/` 里的五份骨架模板。

## 提炼 (Generalization)
"结构"必须与"填充规则"同时交付；只有空目录的脚手架，角色会填错或不敢填。
