# DECISION-20260926-011 — 新增人类输入通道 `management/from_human/`

| 字段 | 值 |
|---|---|
| 决定 ID | DECISION-20260926-011 |
| 日期 | 2026-09-26 |
| 裁决人 | framework_admin (R-001) |
| 触发 | 人类用户指令："请在 management 里面留一个人类给他传输文件的入口文件夹，这样在沟通工作目标的时候可以给 management 具体的文件参考……如果没有请加入，并且更新 management 的工作记忆和人类用户手册等" |
| 依据条款 | `00-ARCHITECTURE §2.1`（无公共工作空间；每块区域一个写入者）、`§2.1.1`（义务闭合性）、`05-CONVENTIONS`（目录自建允许，七目录为最小集） |

## 1. 事实 (Facts)
1. **此前不存在此机制**——核查确认：`management/` 下只有标准七目录（`mailbox` / `memory` / `plan` / `principles` / `role-limit` / `script` / `worklog`），
   人类用户与 `management` 沟通工作目标时**只能口头描述**，无法交付文件参考。
2. 同类先例：`maintainer/code_archive/` 是角色在七目录之外自建的第 8 个目录，已确立"七目录为最小集、允许自建"的做法。
3. 委托层同时要求：**更新 `management` 的工作记忆**与**人类用户手册**。

## 2. 决定 (Decision)
1. **建立 `management/from_human/`** —— 人类用户向 `management` 交付参考文件的**唯一入口**。
   —— 内含 `README.md`（**写给人类看的用法说明**）与 `INTAKE-LOG.md`（**management 维护的登记表，只追加**）。
2. **所有权（关键）**：该目录的**唯一写入者是人类用户**；`management` 对它**只读**——
   **不得修改、移动、重命名或删除**其中任何文件。这条以 **MN14** 明文禁止，并写入权限矩阵作为**唯一例外**。
   理由：那些文件是**委托人的一手依据**；改动它等于篡改需求依据。
3. **处理流程（已内联进 `management` 契约）**：
   - **开工前置新增一步**：扫描 `from_human/` 并与 `INTAKE-LOG.md` 对比，处理未登记文件（§3.1）；
   - **必须登记**：处理后追加一行（文件 / 收到日期 / 用在哪个需求或任务 / 备注）；
   - **以路径引用，不复制内容**：需求拆解书中写路径引用，确保**永远以原件为准**；
   - 读不懂或与需求矛盾 → **发 QUERY 问人，不猜**。
4. **与邮箱的分工**：`from_human/` 收**文件**（人的输入），`mailbox/` 收**邮件**（角色间协议通信）——两者不得混用。
5. **命名建议不强制**：建议 `<YYYYMMDD>-<简短说明>.<ext>`，但人类原文件名同样可用（**不给委托人增加负担**）。
6. **大文件**：建议改为给出路径或链接，不直接投放（避免仓库膨胀）。

## 3. `§2.1` 合规性说明

`from_human/` **不违反**"无公共工作空间"：
- 它**只有一个写入者**（**人类用户**，即委托层），`management` 只读 → 是**单主区**，不是多主共享区；
- 它位于 `management/` **目录之内**（不在仓库根另立顶层区），与 `code_archive/` 的先例同类；
- 它承载的是**人类的输入**，而不是角色之间的协作面。

## 4. 记忆注入说明（与 N2 的关系）

委托层要求"更新 management 的工作记忆"。framework_admin 的处理：

- 本次注入的是 **`LTM-007`（`promoted_from: innate`，confidence 1.00）**——它是一条**规则**（人类文件只读、登记、路径引用），
  依据是**本角色契约的强制约束**（MN14 + §3.1），属记忆模型的"本能"类；
- **这不违反 N2**：N2 禁止的是"替他方沉淀**经验**"（经历者的观察与提炼）；
  而**规则类（innate）条目本来就是在签发契约时注入的**——角色创建时我注入 LTM-000 与全部 innate 条目，正是同一机制；
- 边界保持：**经验型记忆（STM）仍由 `management` 自己写**，我不代写。
