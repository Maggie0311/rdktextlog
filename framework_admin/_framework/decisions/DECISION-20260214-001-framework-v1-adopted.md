## 1. 事实 (Facts)
1. 仓库初始为空（仅存在空的 `framework_admin` 目录），无既有约定需兼容。
2. 人类用户下达硬需求：七项目录、邮箱体系完备、记忆分长期/短期并仿动物记忆与置信规则、边界须严格。
3. 本轮产出：6 份根规范、5 份模板、13 份目录 README、本角色完整七目录实例、6 条长期记忆、3 条短期记忆。

## 2. 决定 (Decision)
1. 采纳 `_framework/` v1.0 为根规范，即刻生效，对全体角色具约束力。
2. 采用"**先规范后实例**"顺序：根规范在所有角色创建之前冻结，避免角色各自漂移。
3. 长期记忆采用 `promoted_from: innate` 机制注入强制约束（记忆模型 §4.1 第 3 条例外），
   经验型记忆一律走 §4.3 的五条件晋升，**不得绕过**。
4. 对一切设计期结论实施置信度封顶 0.85（LTM-006），待真实角色运行后回填验证。
