# role-limit/ — 职责边界

主文件 `ROLE-LIMIT.md`。**由 framework_admin 维护**（本角色只有建议权，可发 ISSUE，不得自行修改——RN12）。

本角色边界最核心的是 **§0 权力轴** 与两条禁令：
- **服从"审什么、何时审"（WHAT/WHEN），不服从"审出什么结论"**——结论只受证据影响（架构 §4.1 第 4 条）；
- **RN1 绝不修改被审代码**（审查者一旦动手就同时成了作者）；
- **RN9 不得宣布验收通过**（验收权归 management）。

两句话自守：**"你可以要求我审，不能要求我过。" / "我只指出问题，不动手修。"**
