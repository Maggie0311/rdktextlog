# CHECKLIST-PYTHON — Python 专项检查清单（v1.0）

> 适用：`scope` 为 Python 的交付。与 `CHECKLIST-COMMON.md` **同时**执行，不可替代。

## A. 语言陷阱

- [ ] **PY-01** 可变默认参数（`def f(x=[])`）？这是**跨调用共享状态**的经典错误。
- [ ] **PY-02** 可变对象共享：浅拷贝 vs 深拷贝是否用错？是否存在意外别名（改 A 影响了 B）？
- [ ] **PY-03** 迭代时修改容器（增删元素）？
- [ ] **PY-04** 闭包的晚绑定（循环变量捕获）导致回调全部使用最后一个值？
- [ ] **PY-05** 生成器 / 迭代器被消费两次（第二次静默为空）？
- [ ] **PY-06** `is` 与 `==` 混用；小整数 / 字符串驻留导致"本机正确、别处错误"？
- [ ] **PY-07** `//` 与 `/` 语义、负数取整、`bool` 是 `int` 子类导致的意外相等？
- [ ] **PY-08** 浮点相等比较与货币 / 精度场景是否使用了 `Decimal`？

## B. 错误处理与资源

- [ ] **PY-09** 异常处理是否过宽（裸 `except:` / `except Exception` 吞掉一切）？是否误吞 `KeyboardInterrupt / SystemExit`？
- [ ] **PY-10** `except` 分支中是否只是 `pass` 或打印后继续（静默失败）？
- [ ] **PY-11** 异常是否被重新抛出时丢失了原始上下文（`raise X` 覆盖了 traceback）？
- [ ] **PY-12** 资源是否用 `with` / `try...finally` 保证释放（文件、锁、连接、临时目录）？
- [ ] **PY-13** 自定义异常是否继承自合适的基类，且携带足够上下文？

## C. 并发与状态

- [ ] **PY-14** 可变全局状态在多线程 / 异步下是否安全？是否误以为"有 GIL 就不会出错"？
- [ ] **PY-15** 异步代码中是否出现阻塞调用（同步 IO / 重计算）阻塞事件循环？
- [ ] **PY-16** `await` 是否遗漏（拿到协程对象却从未执行）？
- [ ] **PY-17** 线程 / 进程池是否在所有路径被 `shutdown` / `join`？

## D. IO、路径与编码

- [ ] **PY-18** `open()` 是否显式指定 `encoding`？（依赖平台默认编码是常见事故源）
- [ ] **PY-19** 文本 / 二进制模式是否用错（`'rb'` 与 `'r'`）？换行处理是否明确？
- [ ] **PY-20** 路径拼接是否使用 `pathlib / os.path`，而非字符串 `+`？
- [ ] **PY-21** 时间处理：naive 与 aware `datetime` 是否混用？是否用了 `datetime.now()` 处理 UTC 场景？
- [ ] **PY-22** 序列化 / 配置读写是否处理了缺字段、类型不符、编码异常？

## E. 依赖与打包

- [ ] **PY-23** 是否引入了未声明的第三方依赖（或未固定版本假设）？
- [ ] **PY-24** 模块级是否有副作用代码（导入即执行 IO / 网络 / 重计算）？
- [ ] **PY-25** `__init__.py` 是否引入了循环导入风险？
- [ ] **PY-26** 是否使用了已废弃的 API（`distutils`、`imp`、`asyncio.get_event_loop` 等）？

## F. 安全

- [ ] **PY-27** `eval / exec / pickle / yaml.load` 是否处理了不可信数据？
- [ ] **PY-28** `subprocess` 是否使用 `shell=True` 且拼接了外部输入（命令注入）？
- [ ] **PY-29** 正则是否存在灾难性回溯（ReDoS）风险？

## G. 质量与可验证性

- [ ] **PY-30** 类型注解与实际行为是否一致（尤其是可能返回 `None` 的函数）？
- [ ] **PY-31** 性能陷阱：循环内 O(n) 查找、对大文本用 `+=` 拼接、重复编译正则
- [ ] **PY-32** `assert` 是否被用作运行时校验（`python -O` 下会被移除）？
- [ ] **PY-33** 测试是否**真的断言**了行为（而不是只调用不检查、或断言恒真）？
- [ ] **PY-34** 日志：是否既用了 `print` 又用了 `logging`（生产代码应统一走 logging）？
