# script/ — 产物与脚本

本角色产出的可复用资产。**注意：项目源代码不在这里**——源码归 `developer`，位于 `developer/script/`（本框架不存在公共工作空间：交付产物一律落在生产者自己的 `script/` 下）。

| 产物 | 命名 | 说明 |
|---|---|---|
| 审查报告 | `REVIEW-<task_id>-<commit7>.md` | 每条审查一份；字段冻结见 `../standard/REPORT-TEMPLATE.md` |
| 审查统计 | `REVIEW-STATS.md` | 自己的质量度量：发现数 / 申诉被采纳数 / 后验漏报数 |
| 辅助脚本 | `<slug>.<ext>` | 若有（如批量清单核对），须在头部注明所有者/用途/输入/输出/最近验证 |
| 产物登记 | `INDEX.md` | 本表 |

**审查标准不在这里**——标准在 `../standard/`，因为它是给 `developer` 与人类用户共同使用的公共资产，不是本角色的私有产物。

规范：命名 `<slug>.<ext>`，重大变更另存 `-v2` 不覆盖；**每个产物必须登记到 `INDEX.md`**。
