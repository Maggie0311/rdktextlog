# short-term/ — 短期记忆

最近几次任务留下的工作记忆。文件命名 `STM-<NNN>-<slug>.md`。

- 容量上限 12 条，超出丢弃最低置信度且低显著性的条目。
- 每条必须写"待验证"，说明晋升还差什么。
- 被晋升的条目标记 `promoted_to: LTM-NNN`，**保留不删**。

本角色**最有价值的短时记忆形态**（示例，尚未发生）：
"当改动涉及资源释放的错误路径时，逐条推演的漏检率明显低于抽样——此类路径应默认全查" —— 有 task_id 证据、可证伪、跨任务可复用。
**不是**："本次审出 5 个 bug"（那是 `REVIEW-STATS.md` 的内容）。
