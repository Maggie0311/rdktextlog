# worklog/ — 工作日志

只追加，不修改历史。

**日志格式（本节即全部要求）**：`#<序号> [YYYY-MM-DD HH:MM] **<动作>**`，下辖 `触发 / 做法 / 理由 / 结果 / 证据`（可选 `后续`）。更正用**新条目**并标注 `[更正: #N]`。
主日志文件：`WORKLOG.md`（按月分节）。
每条日志必须能回答：**触发什么 / 做了什么 / 为什么 / 结果如何 / 证据在哪**。

对本角色额外要求：
- 每条日志写明 `task_id` 与**被审 commit hash**；
- "结果"必须含**覆盖范围**与**结论**（PASS / CONDITIONAL / FAIL），不接受"审完了"三个字；
- 被申诉推翻或降级的判断**必须记录**——那是最有价值的日志内容（RP15 的自我度量依据）。
