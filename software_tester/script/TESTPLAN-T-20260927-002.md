### Q2 步骤（逐条一条命令 + 原始输出）
1. `python3 --version`（及 `python3 -c "import platform; print(platform.machine(), platform.platform())"`）
2. `ls -ld /userdata`
3. journald：`ls -ld /var/log/journal`；`grep -vE '^\s*#|^\s*$' /etc/systemd/journald.conf`；`systemctl is-enabled systemd-journald 2>&1`
4. rsyslog：`systemctl is-active rsyslog 2>&1; ps -ef | grep -i [r]syslog`；`ls -l /etc/rsyslog.conf /etc/rsyslog.d 2>&1`
5. coredump：`which coredumpctl`；`cat /proc/sys/kernel/core_pattern`；`systemctl is-active systemd-coredump 2>&1`
6. dmesg：`dmesg --time-format iso | head -5`（验证 ISO 时间戳形态）

### Q3 步骤（专用探针，落成 UV-1 实测）
1. 参照审查链首轮 `probe_1e/1g` 思路与 developer selftest AC5 组合参数，写**自建对账脚本**（不改被测源码；脚本仅为采集/对账工具，属测试工件）：
   - **组 A（probe_1e 同参）**：单写基线 300 条 max_bytes=1200 keep=3（对照：单进程轮转本身正确）；双进程各 300 条 max_bytes=1200（轮转竞争）。
   - **组 B（AC5 组合参数）**：3 进程各 400 条 max_bytes=8000 keep=20（developer selftest AC5×F-1 用例同参）。
2. 每进程经 `python3 -m rmlog.worker <dir> <count> <max_bytes> [keep]` 拉起；收集各进程退出码。
3. 对账：读 `rmlog.log` + 全部 `rmlog.log.*`，逐行解析 `(wid,i)`，统计：写成功数、磁盘可见数、每 worker 缺号集、重复、半行数、worker 幸存数。
4. 判定：写成功数 == 磁盘可见数 且 每 worker 0..N-1 无缺号、无重复、无半行、无 worker 全灭。
