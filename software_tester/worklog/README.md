# worklog/ — 工作日志

只追加，不修改历史。

**日志格式（本节即全部要求）**：`#<序号> [YYYY-MM-DD HH:MM] **<动作>**`，下辖 `触发 / 做法 / 理由 / 结果 / 证据`（可选 `后续`）。更正用**新条目**并标注 `[更正: #N]`。
主日志文件：`WORKLOG.md`（按月分节）。
每条日志必须能回答：**触发什么 / 做了什么 / 为什么 / 结果如何 / 证据在哪**。

对本角色额外要求：
- 每条日志写明 `task_id`、**被测 commit hash** 与所用**环境**；
- "结果"必须含**原始输出路径**与**覆盖范围**，不接受"测过了"三个字；
- **环境适配**（做了什么、为什么属于非语义适配）必须单独记一条；
- 环境能力发生变化（新设备、驱动失效、远程机不可达）时，必须记一条并同步 `script/ENVIRONMENTS.md`。
