# short-term/ — 短期记忆

最近几次任务留下的工作记忆。文件命名 `STM-<NNN>-<slug>.md`。

- 容量上限 12 条，超出丢弃最低置信度且低显著性的条目。
- 每条必须写"待验证"，说明晋升还差什么。
- 被晋升的条目标记 `promoted_to: LTM-NNN`，**保留不删**。

本角色**最有价值的短时记忆形态**（示例，尚未发生）：
"该板子在 115200 下连续运行 40 分钟后开始丢帧，与 CPU 负载无关，怀疑与 USB 转串口芯片有关；
依据 T-2026-09-26-001 的三次重复实测。" —— 有证据、可证伪、跨任务可复用。
**不是**："今天测了三个用例"（那是 worklog / TESTREPORT 的内容）。
