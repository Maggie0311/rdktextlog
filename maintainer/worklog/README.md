# worklog/ — 工作日志

只追加，不修改历史。
主日志文件：`WORKLOG.md`（按月分节）。
每条日志必须能回答：**触发什么 / 做了什么 / 为什么 / 结果如何 / 证据在哪**。

**日志格式（本节即全部要求）**：`#<序号> [YYYY-MM-DD HH:MM] **<动作>**`，下辖 `触发 / 做法 / 理由 / 结果 / 证据`（可选 `后续`）。
更正用**新条目**并标注 `[更正: #N]`。

对本角色额外要求：
- 每条日志写明 `task_id`、**两封确认通知的 mail_id**、**commit hash** 与归档版本号；
- **答疑也要记**：问的是哪个文件哪一段、我给了什么回答、依据在哪（`file:line`）；
- **解释错误必须留痕**：凡被用户或 `developer` 纠正过的理解，记一条并说明纠正内容——这是本角色最宝贵的日志。
