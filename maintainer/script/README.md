# script/ — maintainer 的产物区

> 本目录是本角色的**过程产物区**。**代码归档不在本目录**——它在 `../code_archive/`。

| 产物 | 命名 | 说明 |
|---|---|---|
| 答疑记录 | `QA-LOG.md` | **每次答疑一条**：问题 / 涉及文件与位置 / 我的回答 / 依据（`file:line`）/ 是否被纠正 |
| 版本差异说明 | `DIFF-<task_id>-<NNN>.md` | 这一版相比上一版改了什么、影响哪些模块（可选产物） |
| 代码走读 | `WALKTHROUGH-<task_id>.md` | 逐模块走读（可选产物） |
| 术语表 | `GLOSSARY.md` | 代码中的命名、缩写、领域词的人话解释（可选产物） |
| 产物登记 | `INDEX.md` | 本表 |

**规范**：命名 `<slug>.<ext>`；重大变更另存 `-v2` 不覆盖；**每个交付单元必须登记到 `INDEX.md`**；
**跨角色流转一律经邮箱**。

> 可选产物（`DIFF` / `WALKTHROUGH` / `GLOSSARY`）是否启用由委托层决定；未启用前不必产出。
