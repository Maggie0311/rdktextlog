# script/ — maintainer 的产物区

> 本目录是本角色的**过程产物区**。**代码归档不在本目录**——它在 `../code_archive/`。

| 产物 | 命名 | 说明 |
|---|---|---|
| 答疑记录 | `QA-LOG.md` | **每次答疑一条**：问题 / 涉及文件与位置 / 我的回答 / 依据（`file:line`）/ 是否被纠正 |
| **项目级术语表** | `GLOSSARY.md` | 代码中的命名、缩写、领域词的人话解释；**跨版本累积**，随版本增补 |
| 产物登记 | `INDEX.md` | 本表 |

> **版本级配套文档不在这里**：`SPEC` / `WALKTHROUGH` / `QUESTIONS` / `DIFF` 都随版本存放于
> `../code_archive/<task_id>/`——它们与**具体版本**绑定，行号与结构都随版本变化。

**规范**：命名 `<slug>.<ext>`；重大变更另存 `-v2` 不覆盖；**每个交付单元必须登记到 `INDEX.md`**；
**跨角色流转一律经邮箱**。

> **四类附加产物已由委托层确认启用**（2026-09-26）：逐模块走读、关键问题清单、版本差异说明、术语表——
> 前三者**每版本必产出**（存于 `code_archive/<task_id>/`），术语表为**项目级**（存于本目录）。
