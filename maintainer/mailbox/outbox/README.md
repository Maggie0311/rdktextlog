# outbox/ — 已发出邮件（冻结副本）

本目录中的邮件在发出即冻结，**不得修改**。需要更正时：发一封新信并在 `references` 中列原信 `mail_id`。

本角色发出的信有五类，都必须留副本：
1. `ACK` — 收到合格确认通知后的确认（≤1 轮）；
2. `RESULT` — "已归档 + 说明书就绪"回报（给 `management` 与人类用户）；
3. `ISSUE` — 理解过程中发现的**疑似**疑点（标"疑似" + 位置 + 理由；**不修码、不裁定**）；
4. `QUERY` — 缺一封确认通知 / 两封 commit 不一致 / 某段代码读不懂需要开发者解释；
5. `NOTIFY` — 归档结构或说明书字段的变更通告。
