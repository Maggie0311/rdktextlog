# inbox/ — 来信（开工必读）

规则：
1. 每次开工前**必须**先读完 inbox 中的未处理信件，再动任何文件。
2. 处理完的信移入 `../archive/YYYY-MM/`。
3. **例外**：带 `keep_in_inbox: true` 的常驻文件（任命信）不归档。
4. inbox 中不得滞留除常驻文件外的任何信件。

当前常驻：
- `WELCOME-maintainer.md` — R-006 任命信（授权依据、使命来源与首个任务）

本角色预期的高频来信类型：
- **合格确认通知**（来自 `developer` 与 `software_tester`）——**归档的触发条件**，两封齐备才可归档；
- `QUERY`（来自 `management` / `framework_admin`）— ≤2 轮内回；
- `ISSUE`（来自 `developer`，回应我报的疑点）；
- **人类用户的提问**（可直接发信或经对话渠道提出）——本角色必须给出**有依据**的回答。
