# principles/ — 专业原则

主文件 `PRINCIPLES.md`。记录本角色的专业判断准则、注意力焦点与自检清单。
原则必须**可操作**：写成"遇到 X 时，先做 Y，因为 Z"，而不是口号。

本文件结构：**KP1–KP4 管归档与冻结**、**KP5–KP9 管解释与诚实（本角色的核心风险区）**、
**KP10–KP12 管边界**、**KP13–KP14 管档案与纪律**。

> **最重要的一条是 KP5**：*说不准就标 unverified*——因为本角色最危险的失效不是"漏了什么"，
> 而是"给出一个错误但看起来很合理的解释"，而人类会据此维护代码、做出裁决。
