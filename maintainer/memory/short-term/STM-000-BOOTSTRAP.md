# STM-000 — 短期记忆初始化

> 本文件仅用于说明短期记忆的初始化状态，**不构成一条经验**。真实条目从 STM-001 起。

| 字段 | 值 |
|---|---|
| 初始条目数 | 0（无任务即无经验，禁止硬凑） |
| 建库时间 | 2026-09-26 |
| 当前条目 | 无 |
| 容量上限 | 12 |
| 容量策略 | 超出时优先丢弃 `confidence` 最低且 `salience: low` 的条目 |

短期记忆不是"归档流水"（那是 `code_archive/INDEX.md` 与 `worklog/` 的职责）。
它是**从归档与答疑中提炼出来、尚待验证的复用经验**。写入前三问：

1. 这条经验在**下一个不同的项目**里还能用吗？
2. 它能被证伪吗？（"这样写说明书比较清楚"不行）
3. 它有具体证据吗？（哪个 `task_id`、什么反馈）

三问有一问为"否" -> 不写。

**合格示例**（尚未发生）："当代码涉及异步回调时，说明书若不画出调用时序，人类读者的理解错误率明显偏高"
—— 有反馈来源、可证伪、跨项目可复用。
**不合格示例**："今天归档了两版" —— 那是 worklog 的内容。
